# Infrastructure

Ce dossier recevra le déploiement reproductible du POC après validation du cadrage.

## Contenu prévu

- manifeste Docker Compose ou automatisation équivalente ;
- versions épinglées ;
- exemples de configuration sans secrets ;
- scripts de vérification ;
- procédures d'installation, mise à jour, sauvegarde et restauration ;
- configuration du pare-feu et des ports ;
- test de charge Jitsi ;
- procédure de révocation d'un compte et d'un appareil.

Aucune infrastructure de production ne doit être lancée directement depuis une configuration non relue.
